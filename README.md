# Logo Site – WordPress Theme

rukanalfareed.com-এর জন্য একটি responsive WordPress theme (logo design studio / portfolio)।

## Hostinger-এ GitHub থেকে Deploy

1. **Branch:** `main` সিলেক্ট করুন।
2. **Deploys to root directory:** `Change` চাপুন এবং লিখুন
   `public_html/wp-content/themes/logo-site`
   (এটা না করলে theme ফাইলগুলো public_html-এ চলে যাবে এবং WordPress সাইট ভেঙে যেতে পারে।)
3. Deploy করুন।
4. WordPress Admin → **Appearance → Themes** → **Logo Site** → **Activate**।

## Customize
- **Appearance → Customize → Site Identity:** লোগো আপলোড করুন।
- **Appearance → Customize → Home Page:** Hero title, subtitle, button, email, WhatsApp নম্বর।
- **Appearance → Menus:** Primary / Footer menu সেট করুন।
- **Portfolio:** Featured image সহ Post তৈরি করলে হোম পেজের "Recent Work"-এ দেখাবে।
